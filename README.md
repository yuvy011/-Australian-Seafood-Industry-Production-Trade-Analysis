# -Australian-Seafood-Industry-Production-Trade-Analysis
A data analysis and visualization project investigating production, aquaculture, and commercial fishing trends across the Australian seafood industry, comparing categories and identifying how the sector has changed over time.
Project Brief
Task: Investigate seafood production, aquaculture, or commercial
fishing in Australia. Compare different seafood categories and identify
trends in production or exports. Explore how the seafood industry has
changed over time.
Approach: Built a structured dataset covering major seafood
categories across both the Wild Catch and Aquaculture sectors,
then analyzed production volume, gross value of production, and export
intensity to answer three questions:
Which categories are growing and which are shrinking?
Is value shifting from wild catch toward aquaculture?
Which categories are most export-dependent vs. domestically consumed?
